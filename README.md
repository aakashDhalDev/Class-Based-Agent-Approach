# Class-Based Agent Approach

This repository presents a modular framework for developing AI agents using a class-based architecture. It facilitates the integration of language models, tools, and prompts to build versatile agents capable of performing complex tasks.

---

## 🧰 Project Structure

- **`agents/`** : Contains class definitions for various agents.
- **`models/`** : Houses configurations and wrappers for language models.
- **`prompts/`** : Includes prompt templates and related resources.
- **`toolbox/`** : Offers utility functions and helper classes.
- **`tools/`** : Defines external tools or APIs that agents can utilize.
- **`main.py`** : The primary script to initialize or run the application.
- **`pyproject.toml`** : Specifies project metadata and dependencies.
- **`uv.lock`** : Lockfile generated by the uv package manager, detailing exact dependency versions.
- **`.python-version`**: Specifies the Python version for the project environment.
- **`.gitignore`**: Lists files and directories to be excluded from version control.

## 🚀 Getting Started

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/aakashDhalDev/Class-Based-Agent-Approach.git
   cd Class-Based-Agent-Approach
   ```

2. **Set up the environment:**

   If using `uv`:

   ```bash
   uv venv
   uv pip install -r requirements.txt
   ```

   Otherwise, using `pip`:

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
